# 📝 Python Script Notes

- `print()` → Shows words on the screen.
- `lessons` → Saves different life lessons and their meanings.
- `lessons.items()` → Gets each lesson and meaning together.
- `for` → Shows each lesson one by one.
- `challenges` → Saves a list of life challenges.
- `input()` → Lets the user type an answer.
- `answer` → Saves the user's answer.
- `{answer}` → Shows the saved answer.

## 💡 What the Script Does

The program shows lessons that are important beyond grades:

**Education → Values → Respect → Resilience → Home → Faith**

It also shows challenges children may face in life.

Then it asks:

> **Besides good grades, what is one thing you want your child to learn about life?**

The idea is simple:

> **Good grades are important, but children also need values and life skills.**
